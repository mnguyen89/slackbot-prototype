MessageKit Reference

Component reference for the Slack message system. Each section shows the real markup patterns and CSS classes used in the webapp. Values sourced from _tools.global_message.less, message-kit/ atoms and containers.

Anatomy

A standard Slack message is composed of nested layers. The outermost container handles background/hover, inside that a flex gutter splits the avatar from the content area.

Parts

background
Outermost painted layer. Handles hover highlight, pinned/starred/ephemeral backgrounds. 6px vertical padding.
gutter
Flex row. Left side is 70px wide (avatar + 8px padding-right). Right side is flex:1.
avatar
36×36px, border-radius 6px. Hidden on adjacent messages (opacity:0, shown on hover).
sender
Font-weight 900 (--dt_static_type-weight-black). Primary text color. Underlines on hover.
timestamp
12px micro text, secondary color. Non-selectable (user-select:none).
body
15px, line-height 1.46667, inline-block, full width. Supports mrkdwn formatting.
reaction_bar
Pill-shaped reaction buttons + add button. 4px margins between items.
reply_bar
34px tall flex row with avatar stack, reply count, and timestamp.
actions
Absolutely positioned toolbar, appears on message hover. Elevation shadow, rounded pill shape.

Core Layout c-message_kit__message

The standard message layout. Avatar in the left gutter, sender + timestamp header, then body text. Source: _tools.global_message.less — light theme with 70px gutter, 8px gap, 26px right padding.

CSS details

.c-reaction
Height 24px, border-radius rounded, 8px inline padding, 4px gap between emoji and count.
--reacted
Blue highlight: --dt_color-content-hgl-1 text, --dt_color-base-hgl-1 bg, 1px blue border.
:hover
1px border via box-shadow, transparent background.
.c-reaction_add
Same shape as reaction, shows smiley face. Subtitle font-size (18px).

Reply Bar c-message__reply_bar

Thread indicator below a message. Shows reply avatars, count, and last reply time. 34px height, 6px border-radius. On hover shows border and "View thread" text. Source: _common.message.source.less.

Actions Toolbar c-message_actions__group

Floating toolbar that appears on message hover. Positioned absolutely above-right. Uses elevation shadow and xlarge border-radius. Each button is 32px square with large radius. Source: _common.message_actions.source.less.
